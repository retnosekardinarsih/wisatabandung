# wisatabandung

An application that contains information about destinations in Bandung. 
Built with Dart and Flutter.


## The Features
### Android App
- #### The List View in the Main Screen
  The insights:
- [x] Using the Card widget to create a list of destinastions.
- [x] Using InkWell widget to give onTap action on the Card.
- [x] Scrollable Card with ListView widget.
- [x] Using ListView.builder to take data on blueprint class of long destination list.
- [x] Using Row and Column widget to create the layout of datas.
![mainscreen](https://github.com/user-attachments/assets/47d8bce3-9a7b-4c31-ad2e-a052c78bc0de)

- #### The Description in the Detail Screen
  The insights:
- [x] Using Column, Row, and Container widget to create the layout.
- [x] Scrollable with SingleChildScrollView widget.
- [x] Using assets for the descriptions and details of destinations.
- [x] Using CircleAvatar to create icon button for onPressed action.
- [x] Create favorite button (just for extra). 
![detailscreen](https://github.com/user-attachments/assets/77420585-2d4b-45e2-9957-a6bfc271c613)
